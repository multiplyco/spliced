<kbd>?</kbd> opens this list inside the app, showing the bindings as they are on your machine. You can change any of them in Settings: click a shortcut, then press the key you want.

## Everywhere

| Key | What it does |
| --- | --- |
| <kbd>⌘K</kbd> or <kbd>/</kbd> | Search, and every action |
| <kbd>?</kbd> | Keyboard shortcuts |
| <kbd>⌘</kbd> <kbd>\</kbd> | Hide or show the sidebar |
| <kbd>Esc</kbd> | Close what is open |

## Tabs

| Key | What it does |
| --- | --- |
| <kbd>Alt</kbd> <kbd>T</kbd> | New tab |
| <kbd>Alt</kbd> <kbd>W</kbd> | Close the tab |
| <kbd>Alt</kbd> <kbd>→</kbd> | Next tab |
| <kbd>Alt</kbd> <kbd>←</kbd> | Previous tab |
| <kbd>Alt</kbd> <kbd>1</kbd> to <kbd>9</kbd> | Go to that tab |

## Library

| Key | What it does |
| --- | --- |
| <kbd>F</kbd> | Filter |
| <kbd>-</kbd> | Smaller cards |
| <kbd>=</kbd> or <kbd>+</kbd> | Bigger cards |

## A scene, open

| Key | What it does |
| --- | --- |
| <kbd>↓</kbd> or <kbd>]</kbd> | Next item |
| <kbd>↑</kbd> or <kbd>[</kbd> | Previous item |
| <kbd>Space</kbd> | Play or pause |
| <kbd>,</kbd> | Back one frame |
| <kbd>.</kbd> | Forward one frame |
| <kbd>←</kbd> | Back one second. With <kbd>Shift</kbd>, a tenth |
| <kbd>→</kbd> | Forward one second. With <kbd>Shift</kbd>, a tenth |
| <kbd>F</kbd> | Favourite |
| <kbd>K</kbd> | Save the frame as a moment |
| <kbd>B</kbd> | Add to the current board |
| <kbd>N</kbd> | Write a note on the scene |
| <kbd>C</kbd> | Copy the brief |
| <kbd>T</kbd> | Copy the time with the ID |
