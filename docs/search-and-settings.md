## Search

<kbd>⌘K</kbd>, <kbd>/</kbd> or the Search field in the sidebar opens one search for everything: scenes, films, boards, a single line on a board, a beat of a film in production, a named move, a look from Styles, a film word. Choosing a result opens the place it lives, already narrowed to it.

The same box runs every action in the app: Go to Boards, Filter scenes, Copy the board's build prompt, Change theme. Paste a link into it to add a film.

Each view that lists things also has its own search bar, top right. It looks further than titles: boards are found by a line of their script, and films in production by a beat or by a note you left. Leaving the view empties its bar.

## Tabs

Several places can be open at once, each keeping its own route and scroll. <kbd>⌘</kbd>-click or middle-click a card or a link to open it in a new tab.

| Key | What it does |
| --- | --- |
| <kbd>Alt</kbd> <kbd>T</kbd> | New tab |
| <kbd>Alt</kbd> <kbd>W</kbd> | Close the tab |
| <kbd>Alt</kbd> <kbd>→</kbd> and <kbd>Alt</kbd> <kbd>←</kbd> | Next tab, previous tab |
| <kbd>⌘</kbd> <kbd>\</kbd> | Hide or show the sidebar |

## The app explains itself

- **Tooltips.** Every control has one. The first waits a moment, and moving from one control to the next they are instant.
- **Film words.** A word with a dotted underline shows its meaning when you point at it. The whole list is the [Glossary](glossary.md), which opens from Settings or <kbd>⌘K</kbd>.
- **View explainers.** The first time you open Library, Boards, Build, Sound or Assets, a few lines say what the view is for. **Got it** puts that one away. **Hide all of these** puts every one away. Settings brings them back, and <kbd>⌘K</kbd>, **About this view** shows the one for the view you are in.
- **The welcome.** <kbd>⌘K</kbd>, **Welcome** opens it again.

## Settings

| Setting | What it is |
| --- | --- |
| Theme | System, light or dark |
| Keyboard shortcuts | Click a shortcut, then press the key you want. Stored in this browser. **Reset all shortcuts** puts them back |
| Service keys | Paste a key for voice-over or a footage library. See [Setup](setup.md) |
| Version | Which Spliced is running, and the exact build when it runs from a checkout |
| What's new | The list of changes, newest first. A dot on the Settings icon says there is something you have not seen |
