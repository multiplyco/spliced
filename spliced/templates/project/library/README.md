# Library

Reference films, broken down scene by scene. Each film is a folder in `references/` with its `breakdown.json`
(what you edit), and the `breakdown.md`, scene strips and `INDEX.md` that `spliced library` writes from it.

| File | What |
| --- | --- |
| `TAXONOMY.md` | The tags a breakdown may use. Add a tag here before using it. |
| `STYLES.md` | What the films do, in your words, linking to the scenes that show it. |
| `INDEX.md` | Every scene by tag. Generated. |
| `state.json` | Your reviews, boards and saved moments. |
| `references.tsv` | Which film is which file, and where it came from. |
